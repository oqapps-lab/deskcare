## Bugs found + fixed in this pass

### P0 — App crashed on Expo Go boot (FIXED)

`Invariant Violation: tried to access a native module that does not exist` blocked first render.

Root cause: `_layout.tsx`, `useAuth.ts`, `paywall.tsx`, `sign-in.tsx`, `sign-up.tsx` all top-level-imported native-only modules (`react-native-adapty`, `react-native-appsflyer`, `expo-apple-authentication`, `@react-native-google-signin/google-signin`). Public Expo Go shell does not bundle them → import-time crash.

Fix: new `lib/native-runtime.ts` exports `IS_EXPO_GO` (= `Constants.appOwnership === 'expo'`). All 4 native imports converted to lazy `require()` inside guarded blocks. New wrapper `components/ui/AppleSignInButton.tsx` renders the official Apple button only when the module loads; returns `null` in Expo Go.

Verified on simulator: app boots cleanly to welcome screen post-fix.

### P1 — Library detail not-found state showed stale CTA (FIXED)

`/library/<bad-slug>` correctly rendered the "This move isn't in our library" not-found body, but the floating bottom CTA + heart icon ("Begin") still rendered on top of it. Now wrapped in `exercise && !notFound && !error && (...)` so the CTA disappears on the not-found and error branches.

### P1 — Force-update screen hardcoded "DESKCARE 0.1" (FIXED)

`app/system/force-update.tsx` had a literal `You are on DeskCare 0.1 · Required 0.2+`. Now reads `Constants.expoConfig?.version` at runtime → `You are on DeskCare 1.0.0 · Required latest`.
