## Infrastructure

- `c630734` — `patch-package` for `expo-calendar@14.1.4`'s `EXFatal` (removed in `expo-modules-core 55.0.25`). `npm run postinstall` re-applies on `npm install`. Without this, archive fails with "cannot find 'EXFatal' in scope".
- Local EAS build pipeline: `eas build --local --profile production` → 22.7 MB IPA → `eas submit` → Apple ingestion 5-10 min.
